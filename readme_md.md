# AI Image Gallery & Metadata Manager

A comprehensive local management system for AI-generated images. This Python project extracts, indexes, and manages metadata embedded in PNG files (such as those generated by Stable Diffusion or DALL-E) and features a content-based recommendation system.

## Features

* **Metadata Extraction (`ImageData.py`, `cfg.py`):** Automatically reads hidden PNG chunks (tEXt, iTXt) to extract generation parameters like Prompts, Models, Seeds, CFG Scales, and Steps.

* **Smart File Tracking (`ImageFiles.py`, `ImageID.py`):** Recursively scans directories to track added or removed images, identifying each unique file with a stable UUID v5.

* **Advanced Search Engine (`SearchMetadata.py`):** Implements an inverted index for lightning-fast text searches across all metadata fields (prompts, models, samplers) with support for boolean operations (AND / OR).

* **Content-Based Recommender System (`RecommenderSystem.py`):** Finds visually or semantically similar images using pre-computed vector embeddings and cosine similarity (optimized with max-heaps).

* **Gallery Management (`Gallery.py`):** Allows users to create, load, and modify custom image collections using JSON formats.

## Technologies & Skills Demonstrated

* **Language:** Python 3.x

* **Libraries:** `Pillow` (PIL), `json`, `uuid`, `heapq`, `os`

* **Concepts:** Object-Oriented Programming (OOP), Inverted Indexes, Vector Embeddings, Binary File Parsing (PNG Chunks), File System Synchronization, Data Structures (Hash Maps, Heaps).

## Project Structure

* `cfg.py`: Core configuration, platform detection, and low-level PNG chunk reading.

* `Gallery.py`: Manages customized user galleries via JSON.

* `ImageData.py`: Stores and manages the metadata for the image collection.

* `ImageFiles.py`: Synchronizes the local file system with the app state.

* `ImageID.py`: Generates and manages collision-free UUIDs for images.

* `SearchMetadata.py`: The search engine using tokenized inverted indexing.

* `RecommenderSystem.py`: The similarity engine processing high-dimensional vectors.

## Setup & Usage

1. Clone the repository.

2. Install the required dependencies:

   ```
   pip install Pillow
   
   ```

3. Place your AI-generated images in the configured `ROOT_DIR` (editable in `cfg.py`).

4. Run the main application (requires an entry-point/UI script to initialize the classes).
